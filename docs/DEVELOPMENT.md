Фактические результаты локальных запусков — `VERIFICATION.md`.

## 1. Распознавание высоты

- [ ] Расширить генератор синтетического PCM: отдельные тесты DC и реалистичных атак.
- [x] YIN, confidence, RMS и проверки диапазона без Android-зависимостей.
- [ ] Все 10 частот при 48/44.1 kHz, разные фазы, отклонения и амплитуды.
- [ ] Тишина, слабый звук, шум, E1, сильная вторая гармоника, за пределами диапазона.
- [ ] Переиспользование памяти и измерение времени анализа.

Приёмка: ошибка ≤1 цента на стабильных чистых сигналах; гармонические тесты
не дают устойчивой октавной ошибки; неуверенный сигнал отклоняется.

## 2. Устойчивое определение струны

- [x] Tracker: медиана, confidence, гистерезис и временное подтверждение.
- [x] Ограничение разумного отклонения, очищение устаревшего результата.
- [ ] Reset при тишине, смене инструмента, остановке записи.
- [ ] Тесты последовательностей: одиночный выброс, реальный скачок, атака и затухание.

Приёмка: единичный выброс не переключает струну; смена режима исключает старые
данные; ±3 цента дают «Настроено» только при стабильной уверенности.

## 3. Android-аудио и жизненный цикл

- [x] AudioRecord: 48 kHz → 44.1 kHz, UNPROCESSED → MIC, PCM16 mono.
- [x] Worker и окно с overlap без неограниченной очереди.
- [ ] Permission flow: первый запрос, отказ, постоянный отказ, возврат из настроек.
- [x] MVVM/StateFlow, ручная DI и сохранение режима через SharedPreferences.
- [ ] RESUMED start/stop, освобождение, dead object, privacy toggle, смена маршрута.

Приёмка: запись идёт только на активном экране, нет утечек и повторных рекордеров;
отказ в разрешении не вызывает падение; сохранённый режим восстанавливается.

## 4. Завершённый экран

- [x] Segmented control, нота/октава, частота, Canvas-шкала ±50 центов.
- [x] Числовые реальные центы, русская подсказка, ряд струн, активность микрофона.
- [x] Все состояния, включая неопределённый сигнал и ошибку микрофона.
- [ ] Анимации стрелки/цвета/ноты с учётом системного уменьшения анимаций.
- [ ] Адаптация к компактным экранам, insets, крупному шрифту и TalkBack.

Приёмка: направление и цвет стрелки соответствуют ТЗ; UI не вычисляет DSP;
нет звука/вибрации и лишних экранов; на типичных телефонах всё без прокрутки.
