# Результаты проверок — 11 ноября 2026

Окружение: Linux, JetBrains JDK 17.0.14, Gradle 9.3.1, AGP 9.1.1,
Android SDK Platform 37.0 revision 2, Build Tools 36.0.0.

```bash
JAVA_HOME=/home/danik/.jdks/jbr-17.0.14 ./gradlew :core:test :app:lintDebug :app:assembleDebug
```

Результат: **BUILD SUCCESSFUL**. Локально прошли 15 unit-тестов; Android lint
не обнаружил ошибок; создан `app/build/outputs/apk/debug/app-debug.apk`.

DSP-тесты используют синтетический PCM16: проверены десять эталонных частот
и расстройка ±100 центов, чистые сигналы на 44,1/48 кГц с разными фазами,
E1, сильная вторая гармоника, тишина, слабый сигнал, шум и частоты вне диапазона.
В покрытых тестами чистых сигналах ошибка не превышает 1 цента. Тесты tracker
проверяют единичный выброс, смену струны, уверенность и сброс при тишине.

`aapt2 dump permissions` показывает RECORD_AUDIO и автоматически добавляемое
AndroidX собственное signature-разрешение для защиты приёмников; сетевых
разрешений нет. APK подписан стандартной debug-подписью.

Системная Java 21 не содержит `javac`, поэтому использован полный JDK 17.
При упаковке debug Compose-библиотека `libandroidx.graphics.path.so` оставлена
без stripping символов; это не препятствует сборке.

## Ещё не проверено

Debug APK установлен и запущен на подключённом телефоне RMX3941 с Android 16;
разрешение микрофона предоставлено. Пользователь сообщил, что проверил приложение
и оно работает отлично. Условия и конкретные результаты испытания на инструменте
не зафиксированы, поэтому считать его полной инструментальной проверкой нельзя.

Отдельно не проверены жизненный цикл, системное отключение микрофона, совместимость
аудиоустройств и режимы отображения. Точность на реальных инструментах, задержка
<200 мс, работа на слабых устройствах, CPU и память не измерялись. Проверки в
GitHub Actions пока не запускались.

По запросу пользователя собран release APK версии 0.1.0 и вручную подписан
существующим ключом проекта LibraryAndroid. `:core:test`, `:app:lintRelease` и
`:app:assembleRelease` прошли; `zipalign -c` и `apksigner verify` подтвердили
выравнивание и подпись v2/v3. APK: `app/build/outputs/apk/release/app-release.apk`.
Автоматическая подпись в Gradle не настроена, релиз на телефоне не установлен.

Детектор использует усреднение по четырём сэмплам перед YIN; его пороги и
предварительная фильтрация требуют проверки на разных микрофонах и реальном шуме.
Окно 8192 отсчёта при 48 кГц составляет 171 мс само по себе, и последующая
стабилизация добавляет задержку. Цель <200 мс не подтверждена.
