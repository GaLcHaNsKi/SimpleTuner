# Матрица проверок

Часть DSP- и domain-проверок автоматизирована в `core/src/test`. Таблица также
содержит проверки, которые ещё нужно выполнить на устройстве; конкретные
результаты и ограничения перечислены в `VERIFICATION.md`.

| Область | Набор данных / действие | Критерий |
|---|---|---|
| Эталоны | Все 6 guitar и 4 bass, A4=440 | Частоты из формулы, верный кандидат |
| Центы | 0, ±1, ±3, −12, +7, ±50, ±700 | Верный знак и величина; число не clamp |
| Чистый PCM | Все 10 частот; 44.1/48 kHz; разные начальные фазы | Ошибка ≤1 цента после заполнения окна |
| Бас | E1 41.2034 Hz, амплитуды и фазы | Нет устойчивого перехода на E2 |
| Гармоники | Основная + вторая в 2–4 раза сильнее, третья | Верная основная или честный отказ; не ложная октава |
| Тишина | Нули, DC | Нет определения, нет «Настроено» |
| Слабый сигнал | Амплитудная сетка, затухание | Ниже порога — отказ и сброс старого результата |
| Шум | Белый шум с фиксированным seed, шум + тон, атака | Нет стабильных ложных нот на шуме |
| Диапазон | 20/34/35/400/401/800 Hz; NaN/Inf для domain | Вне диапазона отклонить, границы проверить |
| Струны | Кандидаты вокруг границ и далеко от строя | Гистерезис, неопределённость вне принятого допуска |
| Выбросы | Устойчивая серия, один неверный фрейм, возврат | Нет одиночного ложного переключения |
| Реальный скачок | Другая струна, плавное вращение колка | Нет чрезмерной инерции; измерить задержку |
| Режим | Guitar ↔ Bass во время звучания/тишины | Reset tracker и новое сопоставление |
| Тишина после ноты | Нота → слабый сигнал → нули | Сброс за установленный timeout, нейтральная стрелка |
| Настройка | ±2.9, ±3.0, ±3.1 цента, низкая confidence | «Настроено» только в ±3 при стабильности |

Для DSP генерировать PCM16, а не передавать готовую известную частоту детектору.
Проверять непрерывные окна с overlap, а не только один идеальный кадр. Seed шума
фиксировать; пороги утверждать по реальным результатам. За пределами диапазона
учитывать возможность октавных субгармоник: одного post-filter недостаточно.

## Устройство и интерфейс

- API 26 и актуальная версия; компактный экран, типичный телефон, увеличенный шрифт.
- Разрешение: первый запуск, отказ, постоянный отказ, настройка системы, отзыв.
- Микрофон: системный privacy toggle, занятость, отключение/смена маршрута.
- Фон/возврат, блокировка экрана, быстрые повторы start/stop, пересоздание Activity.
- Выбранный режим после уничтожения процесса и повторного запуска.
- Тон ниже → стрелка влево/«Подтяни», выше → вправо/«Ослабь»; ±3 → бирюзовый.
- Угол clamp ±50, числовой результат сохраняет реальное отклонение.
- Тишина, неопределённость, ошибка не сохраняют «Настроено» и старую частоту.
- Системная шкала анимаций 0, TalkBack, insets, жестовая и трёхкнопочная навигация.
- Установка APK, запуск без сети, manifest только с RECORD_AUDIO.
- Акустическая гитара и доступный бас; результат синтетики отдельно от результата инструмента.

## Измерение производительности

На устройстве записать модель, Android, sample rate, source, окно/hop,
время DSP p50/p95, end-to-end задержку смены частоты, CPU и аллокации.
Цель — <200 мс на типичных устройствах, особенно проверить низкий бас.
Отдельно проверить отсутствие очереди при медленном DSP и после 10 минут работы.
Не логировать PCM; не путать время одного вызова YIN с общей задержкой тюнера.
